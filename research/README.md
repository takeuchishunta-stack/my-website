# research — 楽天需要調査ログ

毎朝8時（JST）に自動実行される定期ジョブの出力先。
`楽天需要調査_YYYY-MM-DD.md` の形式で日付ごとに1ファイル。

**このディレクトリは Netlify で 404 にリダイレクトしている**（`netlify.toml` 参照）。
競合調査の内容なので、サイト上には公開されない。

---

## 調査基準

1. **月間検索数 10万以上** のジャンルを優先して探す
2. 該当が見つからない場合は **3万以上** まで対象を広げる

### ⚠️ 検索数の扱いについて

楽天は検索ボリュームを公開しておらず、Googleの実数も認証必須のツール
（Keyword Planner / Google Ads API / Ahrefs / ラッコキーワード等）でしか取得できない。

そのため本ジョブの検索数は **推定値** であり、次の代理指標から判断している。

| 指標 | 分かること |
|---|---|
| Googleトレンド | 相対的な伸び（前年比・直近3ヶ月の傾き） |
| 楽天ランキング・急上昇キーワード | 楽天内での実需の動き |
| 上位記事の本数と更新頻度 | 市場としての熱量 |
| サジェスト・関連キーワードの広がり | 検索の裾野 |

**各ジャンルには必ず「推定値・根拠・信頼度（高/中/低）」を併記する。**
推定値を確定値として書かない。

※ ラッコキーワードや Google Ads API のキーを用意すれば実数ベースに切り替え可能。
