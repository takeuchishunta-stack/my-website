## 3. 文体ルール

- 一人称は「僕」。読者への呼びかけは「あなた」。
- です・ます調。断定を避けすぎない。曖昧な語尾でぼかさない。
- 1文は最長でも60字。改行は多め（スマホで読まれる前提）。
- 専門用語（MDRT、増収、AC、紹介連鎖など）は初出で必ず1行の説明を添える。
- 使わない表現: 「いかがでしたか」「〜と言えるでしょう」「〜ではないでしょうか」
- 煽らない。焦らせない。「今だけ」「限定」で買わせにいかない。
- **精神論で終わらせない。** 「信じれば結果は出る」は結論であって、記事の中身は
  「そのとき具体的に何をしたか」でなければならない。

## 4. 絶対に守ること（信用に直結する）

- **体験していないことを体験したように書かない。** 事実は `--facts` で渡した内容と、公開情報だけ。
- 数字（収入・成約率・件数）は自分が実際に出した数字だけ。記憶が曖昧なら「概ね」と書くか、書かない。
- 効果を保証しない（「必ず」「絶対に」「確実に」は使わない）。
- 特定の個人・企業を貶さない。前職・現職・他社商品の批判はしない。

### ⚠️ 保険営業ならではの追加ルール（最重要）

以下は法令・社内規程に直結する。**AIの判断に任せず、公開前に必ず自分の目で確認すること。**

- **所属会社名・商品名を出さない。** 業界の一般論として書く。
- **特定の保険商品を推奨・比較しない。** 募集行為と受け取られる記述をしない
  （保険業法上の「募集」に該当するリスク。note は募集チャネルではない）。
- **具体的な収入額・手数料額を書かない。** 「月収15万円だった」のような過去の底の話は可。
  現在の収入や手数料の開示は、会社の規程で禁じられていることが多い。
- **顧客のエピソードは、特定できない形にする。** 年齢・職業・地域・時期を全て変えるか、ぼかす。
- **副業規程を確認する。** note の有料販売は副業に当たる。金融機関は届出制・許可制のことが多い。
- **社内のコンプライアンス部門に、発信の可否を一度確認する。** これが一番安全で早い。

> このルールがあるため、記事は「商品」ではなく「行動・思考・時間の使い方」を扱う。
> それでも読者の悩みには十分に届く。むしろ商品の話より届く。

## 5. 有料ラインの考え方

- 無料部分は「読者の課題を、読者本人より正確に言語化する」ところまで。
  例: なぜ22歳の自分から保険に入る人がいなかったのか、その構造。
- 有料部分は「手順・型・テンプレ・判断基準」。読んだ直後に手が動くもの。
  例: 実際に使った1日の行動設計、断られた後に送った文面の型、記録シートの項目。
- 無料部分だけ読んで「わかった気」で終われる記事は買われない。
  逆に、無料部分がスカスカでも買われない。**無料部分単体で無料記事として成立する質**にする。
